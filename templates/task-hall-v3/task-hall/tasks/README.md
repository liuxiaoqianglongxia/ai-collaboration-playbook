# Tasks

Task packages are stored as:

```text
tasks/YYYYMMDD/TASK-HALL-YYYYMMDD-NNN.md
```

Each task file uses the standard Task Hall field format:

```text
TASK_ID: TASK-HALL-YYYYMMDD-NNN
PROJECT: <project>
TITLE: <title>
STATUS: READY
OWNER: <agent>
RISK: low|medium|high|destructive
PRIORITY: P0|P1|P2|P3
GOAL: <goal>
SCOPE: <scope>
ACCEPTANCE: <criteria>
```
