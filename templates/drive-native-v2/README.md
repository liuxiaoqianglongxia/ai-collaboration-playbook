# Drive-native V2 Templates

These templates support Drive-native V2 daily collaboration.

Use them in a Drive workbench first. Sync to GitHub only when the content is reusable, stable, release-related, rollback-related, or needed for a milestone summary.

For old-project Level 1 absorption, use these patch-level candidate helpers in this folder:

- `DRIVE_WRITE_FALLBACK_TO_CODEX_TEMPLATE.md`
- `CODEX_CLAUDE_INTERACTIVE_FIRST_PASS_TEMPLATE.md`
- `OLD_PROJECT_ABSORPTION_REPORT_TEMPLATE.md`

Those helpers do not replace this V2 stable template set.
