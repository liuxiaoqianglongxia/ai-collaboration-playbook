# Tasks

> **V3 Task Hall compatibility note**: This template represents the legacy Drive workbench task tracker. Under V3 Task Hall, daily dispatch goes through `task-hall/00_BOARD.md` and `task-hall/tasks/YYYYMMDD/<TASK_ID>.md`. This file remains available for projects that prefer a lightweight view without the full Task Hall CLI, or for historical reference after migrating to V3. It is not a GitHub repo file by default.
