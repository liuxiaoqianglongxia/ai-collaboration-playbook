# Claude Code 只读分析任务模板

> 用途：当 Codex 需要本地工程增强分析时，把本模板适配为 Claude Code 的只读任务文件。V0.2 不做 Claude Code 能力测试，不把本模板接入自动化。

## 任务名

`claude-code-readonly-analysis-<topic>`

## 背景

说明为什么需要 Claude Code 做只读分析，以及该分析如何服务于 Codex 的最终集成。

## 目标

限定为只读分析，例如：

- 梳理调用链。
- 定位测试失败原因。
- 阅读某个模块结构。
- 复审某个 diff 的风险。
- 输出局部修复建议。

## 输入

```text
仓库：<owner/repo or local path>
分支：<branch>
任务文件：<path>
分析范围：<path-or-module>
报告输出：<path>
```

## 只读范围

- 读取指定文件或目录。
- 运行只读搜索命令。
- 阅读测试失败日志。
- 输出分析报告。

## 禁止事项

- 不修改文件。
- 不提交代码。
- 不部署。
- 不改数据库。
- 不改密钥。
- 不改生产配置。
- 不自动运行长期守护。
- 不替代 Codex 做最终集成。

## 输出格式

报告必须包含：

- 结论：PASS / PARTIAL PASS / FAIL / BLOCKED。
- 读取范围。
- 关键发现。
- 证据路径。
- 不确定项。
- 建议 Codex 如何处理。
- 是否建议进入写入任务。

## 验收标准

- 只读，无文件修改。
- 结论有路径或日志依据。
- 明确区分事实、推断和建议。
- 不把建议伪装成已执行结果。
- 不越过 Codex 的最终集成责任。

## 停止条件

遇到以下情况必须停止：

- 需要写文件才能继续。
- 需要生产凭证、数据库或部署权限。
- 任务范围不清。
- 分析发现疑似跨项目污染。
