# ChatGPT Task Package Snapshots

Copy this directory into a project repository only when adopting the GitHub-backed task-package registry compatibility layer.

After copying, this file becomes:

```text
reports/chatgpt/task-packages/README.md
```

## Purpose

This directory stores ChatGPT-issued task package snapshots, independent acceptance records, and review snapshots.

It is project-level evidence. It is not a global playbook upgrade and does not replace `CURRENT.md`, `TASKS.md`, or `reports/latest.md`.

## Naming

Use stable task IDs:

```text
<TASK-ID>-ACCEPTANCE.md
<TASK-ID>-REVIEW.md
```

## Rules

- Preserve task and acceptance evidence as named files.
- Keep project facts in the project repository.
- Do not treat this directory as a substitute for current status files.
