# Codex 提交前检查清单

> 用途：Codex 在 commit / push / 写回报告前确认 diff、测试和禁止范围。

## diff 检查

- [ ] 已查看实际修改文件列表。
- [ ] 修改文件均在任务允许范围内。
- [ ] 没有混入无关格式化。
- [ ] 没有混入其他项目文件。
- [ ] 没有提交本地缓存、构建产物、日志、密钥、数据库、备份包。

## 测试检查

- [ ] 已运行任务要求的测试或检查。
- [ ] 测试结果已记录。
- [ ] 未运行的测试已说明原因。
- [ ] 失败测试已说明是否与本轮相关。

## 报告检查

- [ ] 已写执行报告。
- [ ] 报告包含结论：PASS / PARTIAL PASS / FAIL / BLOCKED。
- [ ] 报告包含修改文件列表。
- [ ] 报告包含测试或检查结果。
- [ ] 报告包含禁止范围确认。
- [ ] 报告包含下一步建议。

## 提交检查

- [ ] commit message 清楚。
- [ ] 没有 force push。
- [ ] 没有越权合并。
- [ ] 没有未经授权部署。

## 停止条件

遇到以下情况不得提交：

- diff 中出现密钥、数据库、生产配置或跨项目文件。
- 修改超出任务允许范围。
- 报告缺失。
- 测试失败且未说明。
- 用户要求先验收再提交。

## 通过标准

只有 diff、测试、报告、禁止范围全部通过，才可提交或请求提交授权。
