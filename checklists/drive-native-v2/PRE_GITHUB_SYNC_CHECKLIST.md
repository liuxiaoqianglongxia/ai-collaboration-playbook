# Pre-GitHub Sync Checklist

- [ ] Output is reusable, release-related, rollback-related, or a milestone summary.
- [ ] Private Drive path is not the only entrance.
- [ ] Worktree status is understood.
- [ ] Branch and base are clear.
- [ ] Candidate status is used before final acceptance.
- [ ] No force push.
- [ ] No production, database, secret, or deployment change.
