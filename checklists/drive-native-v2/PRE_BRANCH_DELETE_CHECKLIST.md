# Pre-branch Delete Checklist

- [ ] Inventory report exists.
- [ ] Branch is listed in inventory.
- [ ] Branch is not main/dev/release/prod/hotfix.
- [ ] Branch is not protected.
- [ ] Branch has merged PR or tip is reachable from origin/main.
- [ ] Branch has no unmerged commits.
- [ ] Force push is not used.
- [ ] Tags are not touched.
