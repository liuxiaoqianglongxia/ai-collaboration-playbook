# Codex 执行前检查清单

> 用途：Codex 在动手执行前确认任务、事实源、范围和停止条件。

## 事实源检查

- [ ] 已读取任务文件。
- [ ] 已读取 `CURRENT.md` 或等价项目状态文件。
- [ ] 已读取 `TASKS.md` 或等价任务列表。
- [ ] 已读取 `AGENTS.md` 或等价执行规则。
- [ ] 已确认当前仓库和分支。

## 范围检查

- [ ] 已列出允许修改的目录或文件。
- [ ] 已列出只读范围。
- [ ] 已列出禁止范围。
- [ ] 已确认本轮是否允许提交。
- [ ] 已确认是否禁止部署、数据库、密钥、生产配置变更。

## 风险检查

- [ ] 是否可能跨项目写入？如果是，停止。
- [ ] 是否需要生产权限？如果是，停止并请求授权。
- [ ] 是否任务目标与事实源冲突？如果是，停止。
- [ ] 是否缺少验收标准？如果是，先补任务文件。

## 执行前确认句式

```text
我已确认仓库、分支、任务文件和允许范围。
本轮允许修改：<paths>
本轮禁止修改：<paths>
本轮验收标准：<summary>
```

## 通过标准

全部检查通过后，才可进入写入或测试阶段。
