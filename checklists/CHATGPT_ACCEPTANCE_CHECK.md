# ChatGPT 验收检查清单

> 用途：ChatGPT 在验收 Codex 或其他执行线报告时使用。验收必须基于 GitHub 事实源，不凭口头描述判断。

## 事实源检查

- [ ] 已读取任务文件。
- [ ] 已读取执行报告。
- [ ] 已读取相关 diff、commit 或 PR。
- [ ] 已读取必要的项目状态文件。
- [ ] 已确认仓库和分支正确。

## 目标对照

- [ ] 执行结果对应原任务目标。
- [ ] 没有偷换目标。
- [ ] 未完成项被明确列出。
- [ ] 外部阻塞被明确列出。

## 禁止范围检查

- [ ] 没有跨项目写入。
- [ ] 没有未授权部署。
- [ ] 没有改密钥。
- [ ] 没有改生产数据库。
- [ ] 没有改生产配置。
- [ ] 没有把实验室内容升级为稳定模块。
- [ ] 没有进行未授权 Claude Code 能力测试。

## 测试与证据检查

- [ ] 测试或检查结果可追溯。
- [ ] 未运行测试有合理说明。
- [ ] PASS 结论有证据支撑。
- [ ] PARTIAL PASS / FAIL / BLOCKED 有明确原因。

## 结论规则

- PASS：目标完成，证据充分，未触碰禁止范围。
- PARTIAL PASS：主要完成，但有明确剩余项或未覆盖验证。
- FAIL：目标未完成、证据不足、测试失败或触碰禁止范围。
- BLOCKED：因权限、凭证、环境或事实源不足无法安全推进。

## 验收输出

验收回复必须包含：

```text
结论：PASS / PARTIAL PASS / FAIL / BLOCKED
依据：<files/commits/reports>
新增风险：<risks>
下一步：<recommendation>
```
