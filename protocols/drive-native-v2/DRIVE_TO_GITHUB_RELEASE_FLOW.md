# Drive To GitHub Release Flow

protocol_id: DRIVE_TO_GITHUB_RELEASE_FLOW
status: candidate

## Flow

1. Work daily in Drive.
2. Validate with Codex report and ChatGPT acceptance.
3. Promote only reusable or release-worthy material.
4. Create a scoped GitHub branch.
5. Open a draft PR for candidate baselines.
6. Promote to stable only after acceptance.

## Safety

- no force push
- no tag deletion
- no deployment unless separately authorized
- no database or secret changes
