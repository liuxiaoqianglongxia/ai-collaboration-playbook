# 005-mcp-docs-context

## 目标

验证 MCP 或连接器文档上下文是否能帮助 Codex 更准确地理解项目工具、接口、外部系统和约束，而不直接执行生产操作。

## 输入

- 用户授权的文档来源。
- 项目 README、接口文档、运行手册或外部工具说明。
- 明确的问题，例如某个工具如何接入、某个限制是否影响当前任务。

## 只读范围

- 读取文档。
- 摘要关键约束。
- 对照项目事实源判断适用性。
- 输出上下文补充报告。

## 禁止事项

- 不调用生产 API。
- 不修改外部系统。
- 不保存密钥。
- 不把外部文档直接覆盖项目规则。
- 不做自动部署。
- 不改业务项目代码。

## 输出

- MCP / docs context 只读报告。
- 报告包含：来源、关键约束、对当前项目的影响、仍需人工确认的问题。

## 验收标准

- 来源清楚。
- 能区分官方文档、项目事实源和推断。
- 没有任何写操作或外部系统变更。
- 能形成后续任务包输入。

## 是否可升级为稳定模块

暂不升级。需要证明它能提升上下文准确性，且不会诱发未授权外部操作后，再考虑稳定化。
