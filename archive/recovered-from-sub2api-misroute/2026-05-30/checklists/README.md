# checklists｜验收清单目录

定位：存放 ChatGPT、Codex、Claude Code 以及部署流程的验收清单。

---

## 1. 计划中的清单

```text
CODEX_READINESS_CHECKLIST.md
CHATGPT_VALIDATION_CHECKLIST.md
CLAUDE_DELEGATION_SCORECARD.md
DEPLOYMENT_CHECKLIST.md
```

当前阶段先建立目录入口，后续按实验和稳定模块逐步拆出正式清单。

---

## 2. 清单原则

清单不是装饰，而是门禁。

每个清单必须回答：

```text
是否已读取事实源？
是否明确启用模块？
是否明确允许范围？
是否明确禁止范围？
是否有测试命令？
是否有报告位置？
是否有停止条件？
是否存在生产风险？
是否可以进入下一步？
```

---

## 3. 默认验收结论

```text
PASS
PARTIAL PASS
FAIL
BLOCKED
```

不得使用模糊结论替代验收。
