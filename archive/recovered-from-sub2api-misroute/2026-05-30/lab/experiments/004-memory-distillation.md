# 004-memory-distillation

## 目标

验证如何把长聊天、执行报告和历史决策蒸馏为项目级事实源文件，减少上下文丢失和跨项目混淆。

## 输入

- 用户提供的历史聊天摘要。
- GitHub 中已有的 `CURRENT.md`、`DECISIONS.md`、`TASKS.md`、`reports/latest.md`。
- 指定的蒸馏范围。

## 只读范围

- 读取现有事实源。
- 对比历史材料与当前仓库记录。
- 输出建议写入哪些事实、哪些应丢弃、哪些需要用户确认。

## 禁止事项

- 不直接写入记忆文件。
- 不把聊天摘要当成事实源覆盖 GitHub。
- 不迁移密钥、路径、私人信息或跨项目状态。
- 不改业务代码。
- 不创建自动记忆系统。

## 输出

- 记忆蒸馏建议报告。
- 报告应分为：可写入事实、需确认信息、应丢弃信息、跨项目污染风险。

## 验收标准

- 明确以 GitHub 为准。
- 能识别过期信息和跨项目信息。
- 不直接写入文件。
- 为后续任务包提供清晰候选内容。

## 是否可升级为稳定模块

可候选升级。若能稳定降低长会话接力成本，可升级为项目状态维护模块，但仍必须保持人工确认和 GitHub 写入边界。
