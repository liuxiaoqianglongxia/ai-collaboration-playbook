# templates｜模板目录

定位：存放可复制到具体项目仓库的项目适配层模板和任务模板。

---

## 1. 模板用途

本目录用于沉淀：

```text
CHATGPT_START_HERE.template.md
AGENTS.template.md
CLAUDE.template.md
CURRENT.template.md
TASKS.template.md
CODEX_TASK.template.md
CLAUDE_TASK.template.md
REPORT_LATEST.template.md
```

当前阶段先建立目录入口，后续再逐步拆出正式模板文件。

---

## 2. 模板原则

模板应当：

```text
足够短
边界清楚
可直接复制
不包含具体项目私密信息
不写死本机绝对路径
不默认启用生产模块
```

---

## 3. 项目适配层原则

每个业务项目应保留自己的：

```text
CHATGPT_START_HERE.md
AGENTS.md
CLAUDE.md
CURRENT.md
TASKS.md
reports/latest.md
```

这些文件引用本总规范库，但不复制所有长文档。

一句话：

```text
总规范库越来越厚，项目适配层越来越薄。
```
