# wsl-server 只读边界说明

本轮 WSL 资产审计暂不扫描 `wsl-server`。

原因：

1. `wsl-server` 被定义为本机生产/部署环境。
2. 禁止把生产环境和开发/实验 WSL 混在一起做资产清理。
3. 禁止在未授权情况下扫描、移动、删除、重启、压缩、提交生产目录。
4. 禁止读取或提交生产 `.env`、数据库、Docker 数据、Cloudflare Token、运行日志、备份。

后续如需审计，只允许执行"生产环境只读健康摘要"，内容限定为：

- 服务名称
- 端口
- 部署目录
- 健康检查 URL
- 备份位置
- 禁止事项

不得输出任何密钥、数据库内容、token、日志正文。
